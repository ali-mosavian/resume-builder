# Resume

One YAML per language, built to DOCX and to self-contained web pages that print to A4.

| Path | What |
|---|---|
| `cv/` | CV content, `cv_en.yaml` and `cv_sv.yaml` |
| `assets/` | Photo; `originals/` holds the original resume downloads (git-ignored) |
| `templates/` | DOCX templates (`pro.docx` is generated by `make_pro_template.py`) |
| `themes/` | Web themes: `<name>.css`, plus optional `<name>.js` / `<name>.*.js` |
| `build/` | Output, git-ignored |

```bash
uv run build_cv.py cv/cv_en.yaml --template templates/pro.docx
```

```bash
uv run build_html.py cv/cv_en.yaml --theme bracket --also cv/cv_sv.yaml
```

```bash
uv run test_build_cv.py
```
